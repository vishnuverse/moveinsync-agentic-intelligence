# Contributing to MoveInSync

We welcome contributions! Please follow these guidelines to help us maintain code quality and project organization.

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Commit changes: `git commit -m "Add your feature"`
4. Push to the branch: `git push origin feature/your-feature`
5. Open a Pull Request

## Code Standards

- Follow project naming conventions
- Write clear, descriptive commit messages
- Include tests for new features
- Update documentation as needed

## Pull Request Process

1. Ensure your PR description clearly describes the changes
2. Link to any related issues
3. Await code review before merging

## Questions?

Open an issue or contact the team leads.
